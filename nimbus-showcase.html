How we got here

Six iterations · one direction
v1Replaced

Smooth-path cloud silhouette

Single SVG path. Cream silhouette, ink eyes and mouth. Looked like a flat sticker.

Lacked the pixel-art identity the brand was reaching for. Read as generic cloud, not as a brand character.

v2Replaced

Pixel grid + brand freckles

Each tile rendered as its own 4×4 rect. Tonal variation (highlight, base, shadow). Three brand-color "freckles" — blue, green, orange — connected the cloud to the ZopCloud mark palette.

Closer to pixel-art identity, but still a generic blob. Freckles felt like decoration rather than meaning.

v3Reverted

Asymmetric cumulus + eye pupils

Split top humps for organic shape. Added eye pupils (2×2 cream highlight inside ink) so the eyes had expression. Cheek blush. Held prop ($) on cheer.

User feedback: the cloud shape was better before. Reverted the silhouette · kept the pupils, blush, and held prop.

v5Replaced

Real ZopCloud logo · with blue backdrop

The actual product mark from /zopcloud.html. Full blue 32×32 backdrop, white cloud silhouette (hump + body), ink face.

Blue box made him feel boxed-in. "Just the cloud icon would work."

v6 · currentLive

Just the cloud · theme-aware

No backdrop, no rectangle. Cloud fills with currentColor — ink on light surfaces, cream on dark. Face features auto-invert.

Same shape as the product logo, but lives transparently anywhere — sidebar, empty states, signin, milestones. Animates emotion every 7–14s.

Why this works

Three principles
01 · Identity

The character IS the brand.

Nimbus is built on the literal ZopCloud product symbol. No invented silhouette. You can spot him as the brand mark from 30 feet away, and the personality reveals itself up close.

02 · Restraint

The body never moves.

Emotion changes only happen inside the cloud — eyes and mouth. The silhouette stays absolutely still, so the brand mark reads as constant even while Nimbus cycles through moods.

03 · Surface

Lives anywhere.

No fixed background, no card, no chrome. The cloud floats over the sidebar, the sign-in pitch, empty states, and milestone toasts — each surface reads it differently, all read it the same way.
