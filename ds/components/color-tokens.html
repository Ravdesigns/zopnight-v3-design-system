Foundation

Color tokens

Every color is a CSS custom property. Light/dark themes flip via one attribute on <html>. Components never use hex values directly.

Brand · core

Five core tokens. Orange is the brand primary; ink + paper carry 97% of the surface area (3% color budget rule).

--zop-orange
Brand primary
--zop-blue
ZopCloud body
--ink
Ink (text & fill)
--paper
Paper (surface)
--bg-app
App background

State · semantic

Four states with matching -bg tints. Tints are used for alert backgrounds; full colors for icons + text.

Theme switching

Toggle html[data-theme="dark"] · every token auto-flips. No per-component dark logic needed downstream.

/* Dark mode auto-flips */
html[data-theme="dark"] {
  --ink: #F4F0E2;
  --paper: #0A0A0A;
  --bg-app: #07070B;
  …
}
