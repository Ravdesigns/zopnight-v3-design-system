Foundation · iconography

Icons

Inline SVG · stroke-based · five canonical sizes · single stroke weight. No icon font. No raster. We don't ship an icon library · we ship a recipe.

The recipe

  • Format · inline SVG. Lives in the markup. No build step, no sprite, no CDN.
  • Stroke-based. fill="none" + stroke="currentColor". Inherits text colour · works in light, dark, and inside buttons.
  • Stroke width · 1.5px. The system weight. 2px only for tiny ≤ 12px icons where 1.5 disappears.
  • Round joins. stroke-linecap="round" stroke-linejoin="round" · softer corners, brand-aligned with the cumulus mascot.
  • Centred on viewBox. Use viewBox="0 0 14 14" for 14px stroke icons, or 0 0 24 24 for 24px.

       fill="none" stroke="currentColor" stroke-width="1.5"

  </svg>

</button>

Custom icon recipe

  1. Open Figma · pick a 14×14 frame · drop the glyph.
  2. Use 1.5px stroke · round caps · no fills (unless solid badge).
  3. Export as SVG · open the file · grab the <path> only.
  4. Wrap with the boilerplate: <svg width="14" height="14" viewBox="0 0 14 14" fill="none" stroke="currentColor" stroke-width="1.5">…</svg>.
  5. Drop into markup. No more, no less.

Provider marks vs UI icons

Two different systems. UI icons are stroke-based and inherit colour. Provider marks (AWS, GCP, Azure, K8s) are brand logos with locked colours · see Provider marks.
