Brand-matched tooltips

Every ApexCharts instance globally inherits ink-pill tooltips with paper text via design.css. No per-chart wiring needed.

/* in design.css (already applied) */
.apexcharts-tooltip {
  background: var(--ink) !important;
  color: var(--paper) !important;
  font-family: var(--font-body) !important;
  …
}

Token wiring

Read tokens from CSS variables at chart-init time so themes flow through.

const css = (n) => getComputedStyle(document.documentElement).getPropertyValue(n).trim();
const tokens = {
  orange: css('--zop-orange'),
  blue:   css('--zop-blue'),
  green:  css('--state-success'),
  ink:    css('--ink'),
  g500:   css('--g-500'),
  line:   css('--line'),
};

new ApexCharts(el, {
  series: [{ data: [12, 18, 22, 28, 34] }],
  colors: [tokens.orange],
  chart: { fontFamily: "'Inter', sans-serif", foreColor: tokens.g500, toolbar: { show: false } },
  grid: { borderColor: tokens.line, strokeDashArray: 3 },
}).render();
