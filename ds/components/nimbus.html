Hands & legs

Every pose now has stubby mitten hands at the side (3-pixel thumb + 3-finger palm on the wave arm) and stair-stepped feet with an ink sole. Walk pose alternates the legs at 0.7s rhythm.

Behaviours

BehaviourDetail
Cursor trackingPupils offset by ±1.2px horizontally · ±0.8px vertically based on cursor direction (clamped). Tracked poses: idle · wave · search · build · peek.
BreathWhole body translates Y by −1.5px on a sine wave. Rhythm varies per pose (2.4s for cheer · 4.4s for sleep).
BlinkEyes close (1-row line) for 110–150ms at random intervals 5–9 seconds apart. Happy/wink/sleep poses don't blink.
Easter eggs~0.012% chance per frame to swap into wink or money pose for 1.8 seconds, then return.
Sleep ZsTwo Z marks · float up + fade · staggered by 1.4s.
Reduced motionAll animations + cursor tracking halt. Eyes stay centered. Easter eggs disabled.

Switching pose at runtime

const el = document.querySelector('[data-nimbus]');
Nimbus.setPose(el, 'cheer');     // celebrate a saving
Nimbus.setPose(el, 'sleep');     // page is idle
Nimbus.setPose(el, 'search');    // user is filtering

// Available poses:
Nimbus.poses;
// ['idle', 'wave', 'search', 'sleep', 'cheer', 'build', 'win', 'money', 'wink', 'peek']
