3% color budget

Rule: state color (orange · red · green) covers ≤3% of any view. Cream + ink + greys carry the remaining 97%.

A screen with too much state color reads noisy and erodes the urgency of the things that actually need attention. Pull state colors back to the badge, dot, or icon · not the whole surface.

Pulse · for "happening now" only

Pulses are reserved for genuinely critical, active state. Don't pulse for "new" · that's what the orange stripe is for.

Reduced-motion contract

Every pulse · bob · slide · scale halts when the user prefers reduced motion. Not optional · already in design.css.

@media (prefers-reduced-motion: reduce) {
  .status-dot.crit::before,
  .sb.critical .dot,
  .sc.err::before,
  .cd.critical .ico   { animation: none; }

  .empty-v3 .n3       { animation: none !important; }

  .card.hoverable:hover,
  .card.active        { transform: none; }

  .drawer-backdrop,
  .drawer-panel       { animation: none; }
}
