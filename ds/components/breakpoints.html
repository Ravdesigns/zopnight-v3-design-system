Foundation · layout

Breakpoints

Five canonical breakpoints. Pull from the tokens · never hard-code 768px in component CSS. The system is desktop-first (the app is a control plane, not a marketing site) but every component degrades gracefully to phone.

The five tokens

TokenValueTarget deviceWhat changes at this size
--bp-sm640pxphone landscapeTables collapse to card list · stat-strip becomes 1-column
--bp-md768pxtablet portraitSidebar collapses to icon rail · drawers go full-width
--bp-lg1024pxtablet landscape / small laptop3-column dashboards drop to 2 · KPI strips wrap
--bp-xl1280pxdesktopDefault · all features at full density
--bp-2xl1536pxwide / external monitorOptional wider gutters · charts get extra real estate

Usage

Media queries don't yet support CSS custom properties directly. The fix is to mirror the token value in a sass map / JS object, or use container queries where supported. For now: copy the value, leave a comment with the token name so future maintainers know where to update.

/* Desktop-first · collapse at md */
.dashboard-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
@media (max-width: 1024px) {  /* var(--bp-lg) */
  .dashboard-grid { grid-template-columns: repeat(2, 1fr); }
}
@media (max-width: 768px) {   /* var(--bp-md) */
  .dashboard-grid { grid-template-columns: 1fr; }
}

Mobile nav drawer

Below md, the sidebar becomes a drawer that slides from the left. Hamburger in the top bar triggers it. Tap outside to close · Esc if keyboard focused.

<button class="hamburger" aria-label="Open menu" aria-expanded="false">
  <svg width="20" height="14" viewBox="0 0 20 14">
    <rect width="20" height="2"/>
    <rect y="6" width="20" height="2"/>
    <rect y="12" width="20" height="2"/>
  </svg>
</button>

<nav class="mobile-nav-drawer" data-open="false">
  <!-- sidebar nav content -->
</nav>

Don't do this

✓ Do 
@media (max-width: 768px) { /* var(--bp-md) */
  .grid { grid-template-columns: 1fr; }
}
Use a canonical breakpoint with a comment naming the token.
✗ Don't 
@media (max-width: 743px) {
  .grid { grid-template-columns: 1fr; }
}
One-off pixel value · drifts from the rest of the system · hard to find later.
