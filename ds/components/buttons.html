Buttons

Five variants (primary · secondary · ghost · upgrade · destructive) at three heights. Each variant ships with a contrast-matched hover bar so the press affordance is unmistakable.

Primary · default size

The most prominent action on a surface. Ink fill on paper, paper fill on ink. One per surface · never two side by side.

<button class="btn btn-primary">Save changes</button>

Don't do this

Common antipatterns to avoid.

✓ Do
Primary action gets the only ink fill. Cancel uses ghost so the eye lands on Save.
✗ Don't
Never use destructive red for a primary save. Never put two ink-filled buttons side by side.
✓ Do
Destructive variant clearly names the consequence.
✗ Don't
Generic labels lose the affordance. Always state the verb + object.

Disabled state

Reduce opacity to 0.45 and disable pointer events. Never just grey out · preserve the variant identity.

<button class="btn btn-primary" disabled>Save</button>
