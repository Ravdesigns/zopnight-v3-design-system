More components

Patterns lifted from the existing OG app and formalised. The first 13 are net-new system additions; the rest are styled in design.css and surfaced here so devs can find them.

Breadcrumb

Trail of links above page title. Last item is the current page (no link).

</nav>

Command palette · ⌘K modal

Global search modal with grouped results. Triggered by ⌘ K. Use data-cmdk-overlay + nested .cmdk-panel · .cmdk-input-wrap · .cmdk-list · .cmdk-row · .cmdk-group · .cmdk-foot. Already styled in design.css.

Already in design.css. Look for .cmdk-* classes. The modal is keyboard-navigated (↑↓⏎Esc) with active row highlighted.

Kebab menu · 3-dot action menu

Compact menu trigger for row-level actions in tables. Same model as .dropdown but with a vertical 3-dot icon button.

<div class="kebab-host">
  <button class="kebab" aria-label="More">⋮</button>
  <div class="kebab-menu">
    <button>Edit</button>
    <button class="destructive">Delete</button>
  </div>
</div>

Toggles · theme · view density

.theme-toggle switches light/dark. .view-toggle switches list/grid view density on data pages.

Metric card · widget grid

For dashboard tiles: .metric-card sits inside a .widget-grid. The card has its own header and chart slot.

Already in design.css. Use .widget-grid for the layout container and .metric-card for each tile. Pair with ApexCharts inline previews.

Timeline · activity stream

Chronological event list used in History and Audit pages. Rows use .tl-row inside .timeline. Each row has time + action + actor.

Already in design.css. Use .timeline > .tl-row. Pair with .path-crumbs for audit-log path display.

Override badge

Inline badge that signals a value has been manually overridden. Different from .tag-pill in that it has a distinct visual mark (small orange tick).

Already in design.css. Use .override-badge.

Auth shell · sign-in / onboarding

Full-page two-column layout: pitch + form. .auth-shell wraps · .auth-aside holds the pitch · .auth-form holds the form. Nimbus waves in the corner.

Already in design.css. Reference signin.html + onboarding.html.

Settings shell · two-column settings

Sticky left nav (.settings-nav) + right pane sections (.settings-section). Already covered in the Settings form pattern · the shell is the page wrapper.

Already in design.css. Reference settings.html.

Keyboard shortcuts help (⌘?)

Modal overlay listing all keyboard shortcuts grouped by section. Triggered by ?.

Already in design.css. Use .kbd-help-overlay > .kbd-help-panel with .kbd-help-group + .kbd-help-row.

Path crumbs · audit/event paths

Monospace path display for audit logs (e.g. resources/i-0a3f9b7c/schedule). Tabular layout with arrow separators.

Already in design.css. Use .path-crumbs.
