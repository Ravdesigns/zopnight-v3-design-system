Edit values in place. Hover reveals pencil hint, click expands into an input with confirm/cancel.

Idle → hover → editing

Hover reveals pencil hint · click puts the row into edit mode with confirm/cancel actions.

</div>

<!-- on click → -->
<div class="ie-row editing">
  <input class="ie-input" value="payments-api-prod" />
  <button class="btn btn-ghost btn-sm">×</button>
  <button class="btn btn-primary btn-sm">✓</button>
</div>
