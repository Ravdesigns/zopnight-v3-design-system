Filter popover

A slim toolbar that collapses a wide filter row behind a single Filters button. Search stays inline; every filter moves into a popover; the active ones surface below as removable pills. Reach for it when a list has four-plus filters that would otherwise overflow the toolbar — for one to three filters, the inline filter row + table is calmer.

Collapsed toolbar

One line: search + a Filters trigger carrying a count badge, with the active filters shown as removable filter pills beneath. The list keeps full width — nothing is hidden, just folded.

Open popover

The popover floats below the trigger (does not push content), holds one labelled control per filter, and ends with a Reset all link and a primary Done. Dismiss on outside-click, Esc, or Done. Width 280–320px; stack labels above controls.

Rules

  • Threshold. Four-plus filters → popover. One to three → inline filter row. Don't mix both on one screen.
  • Search stays out. Keep the search field inline in the toolbar; only the structured filters fold into the popover.
  • Count badge. The trigger shows the number of active filters (not the search). Zero active → no badge, default trigger style; one-plus → is-active trigger + badge.
  • Active pills stay visible. Each active filter renders as a removable filter pill below the toolbar, so state is never hidden behind a closed popover.
  • Float, don't push. The popover overlays content (z-index above the list, below drawers/modals — see composition). Dismiss on outside-click, Esc, or Done.
  • Accent. Active trigger uses the info tint (--state-info), matching the active filter-pill. Reset / Done use the standard button ladder.
