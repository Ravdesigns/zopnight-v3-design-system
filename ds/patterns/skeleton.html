Loading · skeletons

Shimmering placeholders that reserve layout space while data loads. Same shape as the final content so nothing jumps when the response arrives.

Why skeleton?

Reserves layout space while data loads. Prevents content-jump when the response arrives. Should always have the same shape as the final content.
